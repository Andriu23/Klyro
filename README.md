# Klyro — Planificador de tareas

Klyro es una aplicación web diseñada para organizar tareas, planificar actividades y gestionar proyectos de manera sencilla y visual. Permite realizar seguimiento al progreso de las tareas mediante un tablero inspirado en Kanban y Scrum, facilitando la organización del trabajo y el cumplimiento de objetivos.

El proyecto se desarrolla utilizando HTML5, CSS3, JavaScript y Bootstrap 5, con un diseño intuitivo y adaptable a diferentes dispositivos.
